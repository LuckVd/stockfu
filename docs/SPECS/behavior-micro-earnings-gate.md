## 4. 成本压力测试

`cgo_value_top10_v2` full 的成交额为约 5.286 亿元、费用约 41.96 万元，已实现费用约为成交额的 7.94 bp。下面是“固定成交路径、只额外扣除成交额费用”的敏感性估算，不是改变引擎费率后的重跑：

| 额外费用 | 估算总收益 | 估算超额 |
|---:|---:|---:|
| +5 bp | 155.45% | +42.24% |
| +10 bp | 129.02% | +15.81% |
| +15 bp | 102.58% | -10.63% |

在固定路径假设下，full 超额约在额外 `+12.99 bp` 时被完全吃掉；这说明策略有成本缓冲，但不适合把高换手当作无关紧要的实现细节。下一轮若要进入正式保留流程，应给 V2 引擎增加可审计的费率配置并实际重跑，而不是继续依赖该近似。
