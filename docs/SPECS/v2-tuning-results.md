# V2 三策略三阶段调优总结

> 状态：2026-08-13。本文记录价值、高股息、多因子三套 V2 策略的调优流程、最终配置和 canonical 复核结果。数字用于研究比较，不构成收益承诺。

## 1. 目标与结论

本轮目标是把三个候选策略统一改为日调仓，并分别优化执行层、Alpha 因子层和风险覆盖层。最终结论不是“所有参数都越激进越好”，而是保留验证期表现稳定、逻辑清晰的组合配置。

- **最成功：多因子**。2020–2026 年化 14.65%、Sharpe 0.98、最大回撤 12.47%、年化换手 125.77%，收益、稳定性和换手最均衡。
- **可用但需继续优化：价值**。三段收益均为正，但年化换手仍为 344.41%。
- **收益有效但执行未达标：高股息**。2020–2026 年化 11.36%，但年化换手 830.30%，仍是主要问题。

## 2. 统一回测协议

| 项目 | 固定口径 |
|---|---|
| 调仓 | 日调仓；T 日收盘评分，T+1 开盘执行 |
| 股票池 | HS300 历史时点成分 |
| 周期 | `full`、`2013-2019`、`2020-2026` |
| 初始资金 | 1,000,000 |
| 观察窗 | 271 个交易日 |
| 估值/执行 | qfq 收益口径、raw 信号、费用/涨跌停/停牌/整手约束 |
| 数据快照 | `data/snapshots/stockfu-2ee50075f50c.db`，数据末日 2026-08-04 |
| 风险候选 | `no_overlay_v1`、组合刹车、市场状态过滤及组合方案 |

三段独立初始化账户和历史状态，使用同一快照、协议和策略配置。选择顺序是先看 2020–2026 验证段，再看 2013–2019 和 Full 的稳定性，最后参考回撤与换手。

## 3. 三阶段调优流程

### 阶段一：执行层与换手控制

执行层新增并验证了：

- 日内最大进出数量和按 Alpha 排名替换；
- 最低持有周期、漂移阈值和单股票最大仓位；
- 目标权重锁定；
- 根据 FIFO 持仓批次计算最低目标权重，减少刚买入即被反复替换。

测试了两组更强的限频策略：R2（替换 2 只、持有 42 日）和 R1（替换 1 只、持有 63 日）。它们确实能降低换手，但价值和高股息的验证期收益损失较大，因此保留原有 `slow21` policy；多因子采用表现更均衡的 R1 policy。

### 阶段二：Alpha 因子与倾斜

| 策略 | 测试方向 | 最终选择 |
|---|---|---|
| 价值 | E/P 偏重、E/P+B/P 等权、B/P 偏重 | `value_ep_bp_equal_v2` |
| 高股息 | 绝对股息率 75、股息历史稳定性 45 | `dividend_income_history45_v2` |
| 多因子 | 价值、动量、低波动倾斜 | `multi_factor_value_tilt_v2` |

阶段二的核心结果是：价值因子组合应保持 E/P 与 B/P 平衡；高股息需要使用历史稳定性而非只看当前股息率；多因子价值倾斜优于动量和低波动倾斜。

### 阶段三：风险覆盖层

对每个阶段二入选配置分别测试了：组合刹车、市场状态过滤、刹车与市场状态组合。风险覆盖通常降低了部分回撤，但同时牺牲验证期收益或 Sharpe；没有一组在三段上稳定优于无覆盖基线。因此三套最终均采用 `no_overlay_v1`。

## 5. 失败尝试与后续重点

1. 更强的限频 policy 降低了交易次数，但对价值和高股息造成了明显收益损失；不能只按换手最低选择。
2. 风险覆盖层没有形成三段一致的增益，当前不启用。
3. 高股息的高换手主要来自 Alpha/排名变化本身，执行层限制只能缓解，不能根治。下一轮若继续调优，应只围绕股息历史窗口、持有/替换节奏和换手成本做单变量实验。
4. 下一阶段应固定上述配置进入纸面交易/前向验证，记录真实成交率、实际换手、单票权重和成本。
