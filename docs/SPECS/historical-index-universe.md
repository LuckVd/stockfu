# BaoStock 沪深300 / 中证500历史成分宇宙与世界模型

## 决策与目标

世界模型的正式股票数据集固定为 **沪深300（`000300`）与中证500（`000905`）** 在各自生效日的成分股并集。数据只从 BaoStock 的历史成分接口取得：`query_hs300_stocks(date)` 与 `query_zz500_stocks(date)`；不再将中证1000、Tushare 或第三方月度镜像作为默认宇宙的数据来源。

本规格的目标是消除“今天仍在候选池”的幸存者偏差，并让指数调入/调出的时点同时影响世界模型的选股资格与回测执行。指数只定义可选宇宙，不直接决定组合权重。

| 指数 | 代码 | BaoStock 接口 | 最早回测日期 | 单期成员数 |
|---|---|---|---|---:|
| 沪深300 | `000300` | `query_hs300_stocks` | 2006-01-01（接口首个可用交易日） | 300 |
| 中证500 | `000905` | `query_zz500_stocks` | 2007-01-15（接口首个可用交易日） | 500 |

因此 2006-01-01 至 2007-01-14 只能使用沪深300；自中证500首个有效快照起使用两者并集。指数成立前不得倒灌后来的成分名单。

## 数据模型与时点语义

`index_constituent` 必须保存 `index_code`、`asset_code`、`effective_from`、`effective_to`（右开）、`announce_date`、`source`、`source_ref`。每个变更日保存一份完整快照并维护区间，成员资格为：

```
effective_from <= trade_date < effective_to
```

拉取时按本地交易日**串行**扫描 BaoStock，间隔至少 0.3 秒；仅当成员集合相对上一交易日变化时落库。不得只按“六月/十二月的预期调样日”抓取，因为临时调样、合并或退市替换可能发生在其他日期。每次查询必须校验集合基数严格为 300 或 500；空集、接口错误或异常基数均记录缺口并拒绝写入。

`effective_from` 是扫描中第一次观察到新集合的交易日；`effective_to` 是下一份新集合的 `effective_from`。BaoStock 成分接口不提供可审计的公告发布日期，所以 `announce_date` 为空，`source` 明确标为 `baostock_*_snapshot_unverified`，`source_ref` 保存接口和查询日期。回测订单本来就在当日收盘形成、下一交易日开盘执行；不得用同日收盘前的未知调样信息成交。若未来获得指数公司公告，应以公告发布日期和生效日交叉验证/替换对应区间。

## 世界模型的两层池

世界模型必须区分以下集合，不能把“被调出”误解成“立即强平”或“永久冻结”。

| 集合 | 组成 | 允许行为 |
|---|---|---|
| 入选池 `E(t)` | 当日有效的 300/500 成分 ∩ 上市/非ST/交易状态/流动性等既有严格过滤 | 可计算完整候选信号；可新开仓、加仓、替换 |
| 持仓管理池 `M(t)` | `E(t)` 加上期初仍持有且有可用估值/行情的股票 | 可计算退出、止损和减仓信号；仅 `E(t)` 成员可得到正向新增目标 |

调入股票从其 `effective_from` 起进入 `E(t)`，仍需满足上市满60日等既有可交易过滤。调出股票自 `effective_to` 起立即离开 `E(t)`：不得参与截面排名、不得新买或加仓；但若期初已持有，必须留在 `M(t)`，继续计算其卖出、止损与减仓条件。其退出目标可低于当前仓位（包括零），其任何目标不得高于当前仓位。停牌时仍以最近可得价格估值，并沿用既有的延迟卖单/成交限制，不能因为调出而伪造可成交价格。

实现上，不能把宇宙外持仓直接设为 `desired=None` 后跳过分析；那会使普通卖出与止损永不触发。应为“持仓管理池中的宇宙外股票”运行仅退出方向的信号路径，再在组合层施加 `target_weight <= current_weight` 的硬约束。ST 强制退出、退市处理和交易可达性规则仍优先于该路径。

## 当前实现核查（2026-07-25）

1. **数据集不符合新决策。** 默认值仍为 `000300 + 000852`，标识为 `cn_historical_csi300_csi1000_v1`；库中 `000852` 只有 2025-04-01 起的月度镜像。它必须退出默认宇宙，不能与新数据集混用。
2. **沪深300历史快照基本符合扫描设计。** 库中有 69 个变化快照，覆盖 2006-01-04 至 2026-07-24、累计 940 只；变更日期不只限于半年度，已包含临时变动。来源仍是 BaoStock，尚未由指数公司公告逐期核验。
3. **中证500尚未导入。** 当前库没有 `000905` 行，也没有 `fetch_baostock_zz500_snapshot` / 回补命令，因此当前“300+500”数据集尚未可用。
4. **调出后的选股限制已部分正确。** `UniverseContext.eligible_on()` 按右开区间过滤，调出日不再进入候选池；历史并集也会保留其证券代码和行情。
5. **调出后的持仓退出不正确。** 当前引擎把宇宙外持仓排除于普通信号和止损分析，仅允许维持（ST例外），不满足本规格的持仓管理池要求。

## 实施顺序与验收

1. 抽象 BaoStock 成分快照抓取器，支持 `000300` / `000905`，并增加中证500按交易日串行回补命令；默认指数、宇宙 ID、CLI 输出、全周期任务和测试改为 `000300 + 000905`。旧中证1000数据保留归档，不删除、不参与默认回测。
2. 对每份快照校验成员数、重复代码、相邻快照 diff、首末覆盖和每个区间连续性；报告各指数累计去重数、并集数、每个变更日/年度的可交易数量以及缺口。网络失败不得以临近快照补写。
3. 在世界模型/回测引擎实现 `E(t)` 与 `M(t)` 分层：宇宙外持仓可触发退出，但所有增加仓位的路径必须受 `E(t)` 约束。记录每笔交易的成员资格、调入/调出区间和“exit-only”原因，供审计。
4. 扩充 `security_master` 和行情、估值、分红覆盖到两个指数的历史并集，包括后来退市股票；调出后数据继续保留，以支持估值、卖出与分红税处理。
5. 增加单元/集成测试：右开边界、调入可买、调出不可买不可加仓、调出后普通卖出、调出后止损、停牌延迟卖出、指数成立前排除，以及 300/500 同日交集去重。
6. 只有中证500回补、覆盖审计和上述退出路径均通过后，才运行并解读新宇宙的 2006–2026 与 2013–2026 回测。结果必须携带新的 `universe_id`、数据源版本和覆盖/缺口报告，旧 `cn_large_pool_v1` 与 `cn_historical_csi300_csi1000_v1` 结果仅作历史对照。

## 非目标

- 本期不纳入中证1000、创业板指、科创50或指数权重。
- 不因指数调出而强制卖出，也不删除其后续行情、估值或分红数据。
- 未获得正式公告前，不将 BaoStock 数据称为指数公司正式档案。
