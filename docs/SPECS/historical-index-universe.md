# 沪深300 / 中证1000历史成分宇宙与回测

## 目标

把个股策略的基础池从“今天仍在候选池中的股票”改为按交易日变化的历史指数成分股并集，消除当前池的主要幸存者偏差。首个用途是以 `dividend_cross_section#sl30` 重跑 2006–2026；2013–2026 也必须在新宇宙下重跑，不能与旧结果混用。

## 范围与指数口径

历史宇宙为下列指数在每个交易日生效样本的去重并集：

| 名称 | 代码 | 单期样本数 | 可参与的最早时期 |
|---|---|---:|---|
| 沪深300 | `000300` | 300 | 2006-01-01 |
| 中证1000 | `000852` | 1,000 | 以正式历史样本数据的首个生效日为准 |

指数成立前不得用今天的成分或后来的股票名单倒灌。每个交易日仅使用 `effective_from <= T < effective_to` 的样本；随后再执行策略已有的上市满 60 日、ST、停牌、成交额等严格可交易过滤。

## 数据与实现要求

1. 新建历史成分表，至少保存 `index_code`、`asset_code`、`effective_from`、`effective_to`、`announce_date`、`source`、`source_ref`。变更公告必须可追溯，临时调样和退市替换也必须入表。
2. 数据源优先采用中证指数、国证指数、上交所发布的正式历史样本/权重文件及调样公告；不能以当前成分接口替代历史档案。下载失败、档案缺失或生效日不清晰时记录为缺口，不伪造区间。
3. 扩充 `security_master` 与基础证券池至所有“历史上曾入选”的股票，包含后来退市的股票及其上市/退市日期；保留股票代码变更映射。
4. 为所有历史成员回补三复权日线、PE/PB 与交易状态。为 2006-01-01 的三因子首日有效计算，行情预热至少回补至 2000/2001（价值因子 5 年、低波因子 3 年）；现金分红至少回补至 2005-01-01（TTM 股息率）。
5. 账户继续使用 raw 价格成交/估值、除息日现金分红与持有期红利税；信号与技术因子继续使用 qfq 价格。不得因补历史宇宙改变该税后收益口径。

## 交付与验收

1. 生成审计表：各指数历史累计去重数、四指数并集累计去重数、每个调样日和每年可交易股票数、与旧 815 只池的交并差。
2. 任意日期查询必须只返回当时已生效的成分；退市/调出股票在失效日后不得新开仓。
3. 行情、估值和分红覆盖率分别按 `index_code`、年份、复权口径统计；缺口股票与原因输出到报告。
4. `dividend_cross_section#sl30` 在新宇宙上完成 2006–2026 和 2013–2026 两次独立回测，结果带有 `universe_id`、成分版本、覆盖率与缺口说明，旧 `cn_large_pool_v1` 结果保留为不可直接比较的历史对照。
5. 增加单测：生效区间边界、调入/调出、指数成立前排除、成分并集去重、退市与上市 60 日规则。

## 非目标 / 待确认

- 本期不把指数权重直接用于持仓权重；指数只定义可选股票宇宙。
- 创业板指与科创50不属于当前正式回测宇宙；已归档的数据不参与默认策略。未来如重新纳入，须先补齐初始名单与每期调样链并单独验收。
- 在历史成分数据完整性与累计股票数量审计完成前，不发布或解读 2006–2026 的策略绩效。
