情绪指数怎么算

三个指数均为 0–100，采用 CNN 式算法：每个因子取近 5 年历史分位，再按方向等权平均。
恐慌指数下行因子（波动率分位 + 跌幅分位）。值越高 = 市场越恐慌。
贪婪指数上行因子（涨幅分位 + 成交分位 + 资金流入 / 连板 / 两融）。值越高 = 越贪婪。
热度指数成交活跃度分位。值越高 = 越放量。
表情档位每个指数从低到高对应 5 档表情：恐慌 😌🙂😐😰😱；贪婪 😌🙂😐😁🤑；热度 ❄️🌤️😐🥵🔥。
热度方向热度按当日涨跌着色：红 = 买入热（涨）、绿 = 卖出热（跌）；数字是强度（0-100）。
三层粒度：大盘（沪深300 基准）/ 板块 / 个股，算法相同。点击持仓表里的代码，可看个股各因子的分位明细。
